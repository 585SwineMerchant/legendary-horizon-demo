Narration audio drop zone
=========================

Place the exported narration files here:

- scene_1_awakening.mp3
- scene_2_base_stats.mp3
- scene_3_library.mp3
- scene_4_scroll.mp3
- scene_5_comparison.mp3
- scene_6_return_to_maia.mp3

Short MP3 files are recommended for browser compatibility. The intro screen will attempt to play each file when its scene starts and will continue silently if the audio is missing.
